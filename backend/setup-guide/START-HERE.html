Browser setup

    Your browser requires these permission steps. Spoilence does not change browser profiles or silently enable extensions.

    A little help, if you need it.

    I opened a file without extracting the ZIP.

    Extract your named spoilence_browsername.zip into a permanent folder. Load that extracted folder directly in your browser.

    The browser says this is a development extension.

    This build uses developer installation. Firefox temporary installs disappear when Firefox closes. A signed store release will remove these development steps; one is not included yet.

    Is every browser supported?

    Each browser gets a named ZIP containing only its extension runtime and required licenses. The guide stays outside the ZIP. The manifest is directly in the extracted folder. Compatibility depends on the browser supporting modern WebExtensions. Forks still need individual runtime validation. Mobile browsers and browsers without compatible extension APIs are outside this release.

    What should I expect from protection?

    Spoilence targets GTA VI. Hide removes the whole detected item. Blur applies a 32px thumbnail blur and the safe title "Spoilence Protected - GTA 6 Leak", preserving recognized channel, views and time details. Unknown layouts use a conservative cover. Image-only spoilers, unsupported languages and changed layouts can be missed. Nothing analyses audio or video. Use the popup to change modes, adjust sensitivity or clear local data.
