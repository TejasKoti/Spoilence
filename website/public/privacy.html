Spoilence is an independent browser-extension project. This page describes the extension and this download website separately.

The extension

Detection uses local text rules and accessible page metadata on supported YouTube, Instagram and TikTok layouts. It adds no detection-related network requests. There is no server inference, account, telemetry, analytics or automatic rule download.

Raw page content is processed in memory and is never written to disk by Spoilence. Decisions live in a bounded memory cache with opaque identifiers. Each decision expires no later than 24 hours from creation; reading it does not extend its lifetime. OFF and Clear Data clear decisions. Resume and clock rollback discard stale state.

Only non-content preferences and explicitly imported, validated rule packs may remain in extension local storage. Full reset removes those too. No screenshot capture, OCR provider, image classifier, audio analysis or video analysis is enabled.

Your controls

Open the extension popup to change Hide/Blur, sensitivity, per-site preferences or protection status. You can reset local data there. After removing or externally disabling the extension, reload open tabs to clear already-injected covers. Spoilence cannot erase a website's, browser's or operating system's own caches.

This website

The site serves its scripts, fonts, artwork and extension download from the same host. It contains no analytics, tracking pixels, cookies, browser storage, external embeds or third-party font requests. Browser identity is read locally to suggest installation instructions. Pointer position is used only while interacting with the artwork; it is not recorded, retained or transmitted.

Visiting or downloading files necessarily sends normal HTTP requests to the hosting provider. The site is configured for Cloudflare static hosting. Cloudflare and any infrastructure settings chosen by the deployer may process request metadata such as IP addresses and user agents. Extension detection does not send browsing content to this website or Cloudflare.

Coverage and independence

Each website download asks you to accept the Terms of Use. The checkbox resets for every request. Acceptance is not stored in cookies, browser storage or a server-side agreement log by this site.

This development release is for compatible desktop browsers. It can miss spoilers and has no signed store release included. Safari and individual browser forks have separate validation limits. Spoilence is not affiliated with Rockstar Games.
